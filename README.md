# Bibliothèque Java

Petit projet Java en ligne de commande pour gérer une bibliothèque de livres.

## Fonctionnalités

- Afficher les livres et leur catégorie.
- Rechercher un titre sans tenir compte des majuscules et minuscules.
- Ajouter et supprimer des livres, en refusant les titres invalides et les doublons.
- Compter les livres longs et trouver le livre qui a le plus de pages.
- Conserver une copie indépendante de la liste reçue par la bibliothèque.

## Prérequis

Java 11 ou version ultérieure (le projet a été exécuté avec Java 17).

## Exécution

Depuis la racine du projet, compiler les fichiers Java puis lancer le programme :

```sh
javac src/*.java
java -cp src Main
```
